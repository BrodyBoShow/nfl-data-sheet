# P6 — Data sheet UI

**Status:** not started (blocked on P5)

## Scope
- Scaffold `/web`: Next.js App Router + TypeScript, deployed to Vercel.
- Reads Supabase only via views (no external calls, no direct writes from the UI).
- Game view, player view, signal cross-reference and filters.
- Matchup cards showing sample sizes and data-freshness/staleness badges (from the
  auditor's per-domain status).

## Data licensing obligations (carry into the UI)
- **Open-Meteo (weather, P4) — CC BY 4.0.** Every place weather appears (matchup card
  weather block, game view, any wind/precip badge or tooltip) must carry a visible credit,
  e.g. "Weather data by Open-Meteo.com" linked to https://open-meteo.com/. A single
  site-wide footer is not enough on its own if a card can be viewed or screenshotted
  without it — put the credit on the weather block itself.
- **Open-Meteo free tier is non-commercial only**: no ads, no subscriptions, no paywall
  on the deployed app. Adding any of those means moving to a paid Open-Meteo plan first
  (see `docs/sources.md`).
- **OpenStreetMap (stadium coords / `field_bearing`, P4) — ODbL.** Credit
  "© OpenStreetMap contributors" wherever stadium-derived data (e.g. headwind/crosswind
  framing) is shown, or in an app-wide data-sources/credits page that the weather block
  links to.
- **Wind wording**: weather wind values are exterior 10 m estimates, not field wind
  (`docs/sources.md`). UI copy must not say or imply "wind at the field" — label as
  e.g. "Outside wind (10 m est.)".
