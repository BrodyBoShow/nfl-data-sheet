ALTER TABLE club_rss_items ENABLE ROW LEVEL SECURITY;

CREATE TABLE sleeper_adds (
    sleeper_id   text PRIMARY KEY,       -- Sleeper's player_id: numeric, or a team code (team defense)

    player_id    text,                   -- gsis via crosswalk.sleeper_id; set for 'player' and 'no_players_row'

                                         -- 'team_defense': the code, mapped (see LAR), if active

);
ALTER TABLE sleeper_adds ENABLE ROW LEVEL SECURITY;

-- D18: one row, the latest fetch, replaced in the same transaction as sleeper_adds.
CREATE TABLE sleeper_adds_fetch (
    id             smallint PRIMARY KEY DEFAULT 1 CHECK (id = 1),
    fetched_at     timestamptz NOT NULL, -- the label's "as of" (D6)

## Requirements on any new collector (from P7, filed 2026-10-07)
P7's input gate and server-side hash diff change what a collector has to do. Neither
was in this file before.
1. **Store through `upsert_changed`** (`pipeline/core/db.py`), with a `content_hash`
   column. Return `rows_changed`, not rows attempted.
   - Any `rows_written > 0` fires Efficiency, Availability impact, Environment and
     Market that tick (`dispatcher._run_tick`). A poll that changed nothing must report
     0.
2. **That coupling remains even when the count is right.** A real write fires the four
   ungated analysts. The marginal cost is about zero today, because Availability writes
   on nearly every tick. A new T1 collector still inherits it.
3. **A new analyst input is a gate input.** The architecture draws Intel → Availability
   impact and Live → Market. Neither edge is in this file's scope. If either is built, a
   gated analyst needs a declared `GateInput` for the new table.
4. **An auditor check.** A tier `FreshnessCheck`, or a schedule-aware check like odds
   and weather have, for a source with legitimate gaps (Live, between game windows).
5. **No by-age deletes outside `retention.py`** (CLAUDE.md; Q3).
6. **The two rules added to CLAUDE.md, 2026-10-01..05, apply to tagging and linking:**
   "Missing row ≠ NULL column" (Q2) and "A row's label comes from the row" (Q4,
   categories).
