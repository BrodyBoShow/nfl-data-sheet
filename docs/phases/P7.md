## Scope
- Usage and role analyst: snap share, target share, air-yards share, red-zone/goal-line
  share, carry share, week-over-week deltas. Reads the `player_week`/`snaps` staged
  tables already populated by the Phase 2 nflverse bulk collector — no new external
  source needed.
- Scheme analyst: pass rate over expected, neutral pace, play-action/motion rate, box
  counts, blitz/pressure rate, approximate personnel (explicitly labeled as approximate).
  Reads the `ftn` staged table from the same Phase 2 collector.
- Intel collector: ESPN NFL news feed, official team RSS where available, Sleeper
  trending players as a news-spike indicator. Dedupe by URL + text hash.
- Rule-based tagging only (keywords + crosswalk name matching) — team, player_id,
  category (injury, depth chart, suspension, coaching, signing/release/trade). No LLM
  calls.
