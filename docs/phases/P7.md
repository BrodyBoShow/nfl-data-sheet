  counts, blitz/pressure rate, approximate personnel (explicitly labeled as approximate).

  trending players as a news-spike indicator. Dedupe by URL + text hash.
- Rule-based tagging only (keywords + crosswalk name matching) — team, player_id,
  category (injury, depth chart, suspension, coaching, signing/release/trade). No LLM
  calls.
